# 워크숍 전에 준비할 것

처음이라면 **내 컴퓨터 + Hermes Desktop 앱 + 채용 신호 + 연습 데이터 + 템플릿 초안** 조합이 가장 쉽습니다.
API 키나 봇 계정 없이 첫 결과를 확인하고, Telegram·Discord, 실제 공개 데이터, 서버의 계속 실행은 그 뒤에 붙입니다.

## 1. 노트북에서 준비하기

- Mac 또는 Windows 노트북과 충전기, 저장 공간 5GB 이상
- 회사 보안 프로그램이 새 앱 설치를 막는다면 사내 담당자 승인
- 이 키트 폴더를 압축 해제한 위치
- 선택: 저장소 파일을 읽고 명령을 실행할 수 있는 Codex, Claude Code, Gemini CLI 같은 코딩 AI

코딩 AI가 없어도 `start.py`를 실행하면 질문부터 설치·재개까지 이어집니다. `wizard.html`은 브라우저에서
설정 파일만 따로 만들고 싶을 때 쓰는 선택 사항이며, 파일 다운로드 자체가 설치 완료는 아닙니다.

Python이 없는 새 컴퓨터는 바로 `prepare.py`를 실행할 수 없습니다. 먼저 [설치 지원 안내](INSTALL-ASSISTANT.md)의
“Python이 없을 때” 절차로 공식 Hermes 설치 파일을 내려받아 hash를 확인하세요. 보안 기능을 끄거나
인터넷 스크립트를 바로 shell로 넘기지 않습니다.

## 2. 오늘 할 일 하나 고르기

| 선택 | 의미 | 처음 권장 데이터 |
|---|---|---|
| 채용 신호 | 채용공고가 있는 회사를 검토 후보로 모음 | 연습 데이터 또는 회사 공개 ATS |
| 투자 신호 | 투자 소식이 있는 회사를 검토 후보로 모음 | 연습 데이터 또는 내 파일 |
| 입찰 확인 | 관심 키워드의 공고를 모음 | 연습 데이터 또는 내 파일 |
| 해외 파트너 | 해외 파트너 후보를 정리 | 연습 데이터 또는 내 파일 |

신호는 구매가 확정됐다는 뜻이 아닙니다. 왜 후보가 되었는지 근거를 보고 사람이 판단하는 출발점입니다.

내 파일을 쓴다면 CSV 또는 JSON 파일 경로를 준비하세요. `채용 신호 + 실시간`을 고르면 회사 공개
채용 페이지가 Greenhouse, Lever, Ashby 중 무엇인지와 게시판 식별자가 필요합니다. 로그인·CAPTCHA·
유료 장벽을 우회하지 않습니다. 현재 live 연결이 없는 시나리오는 내 파일 또는 연습 데이터로 진행합니다.

## 3. 선택 기능은 필요한 사람만 준비하기

### 모델

연습 데이터와 템플릿 초안은 유료 AI 계정 없이 확인할 수 있습니다. 실제 AI 초안을 원할 때만 Hermes가
현재 지원하는 로그인 또는 API 인증을 선택합니다. ChatGPT 웹 구독과 API 사용 권한은 같지 않을 수 있습니다.

### Telegram 또는 Discord

처음부터 필수는 아닙니다. 선택한다면 Telegram의 BotFather에서 만든 봇과 본인 숫자 ID, 또는 Discord
Developer Portal의 앱/봇, Message Content Intent, 초대한 서버와 본인 숫자 ID를 준비합니다. 봇 토큰은
채팅, `setup.json`, ZIP에 넣지 않고 사용자가 직접 연 비공개 터미널의 숨김 입력에만 넣습니다.

### 서버

서버는 이미 발급받아 접속 정보가 있는 참가자용입니다. **SSH는 내 컴퓨터에서 서버에 안전하게 접속하는
방법**입니다. 클라우드 화면에서 서버 주소/IP, 사용자 이름, 포트(보통 22)를 찾으세요. SSH 개인키는 내
컴퓨터에만 두고 `.pub` 공개키만 서버에 등록합니다. 접속, 배포, 수동 실행, 재부팅 후 실행을 각각 확인합니다.

### OmniRoute

선택 기능입니다. Docker Desktop 또는 Docker Engine, Compose, Docker에 할당된 메모리 4GiB 이상이
필요합니다. 첫 결과만 볼 사람은 준비하지 않아도 됩니다. OMH는 권장 기본값이며 사용자가 끌 수 있습니다.

## 4. 설치 폴더

- Mac/Linux: `~/.hermes-outbound`
- Windows: `%LOCALAPPDATA%\hermes-outbound`

결과 폴더의 기본 예시는 `~/hermes-outbound-results`입니다. 기존 파일은 자동으로 덮어쓰지 않습니다.

## 5. 시작하기

코딩 AI에는 다음 한 문장을 보냅니다.

> `agent-skill/hermes-outbound-setup/SKILL.md`를 읽고 질문을 조금씩 하면서 설치해줘. 비밀값은 채팅에 묻지 마.

Python이 이미 있다면 하나의 시작 명령을 실행합니다.

```sh
python3 start.py --help
python3 start.py
```

Windows PowerShell에서는 `python3` 대신 `py -3`을 사용합니다. 계정 없이 연습 데이터부터 보려면
`python3 start.py --offline`을 사용합니다. 첫 성공 기준은 “설치됨” 표시가 아니라
후보 회사, 선택 이유의 근거, 사람이 검토할 메시지 초안, 결과 파일 위치가 함께 보이는 것입니다. 예약
실행은 수동 실행이 성공한 뒤에만 켭니다.
