# 레퍼런스 통합 감사

레퍼런스를 읽었다는 사실과 기능을 배포 키트에 연결했다는 사실은 다릅니다.
각 감사 문서는 원본 파일·검토 커밋·라이선스·가져온 부분·제외 이유·테스트를 기록합니다.
아래 상태는 전면 재감사 후의 연결 상태이며, 근거는 각 담당 문서에 남깁니다.

| 레퍼런스 | 검토 목적 | 현재 연결 상태 |
|---|---|---|
| hermes-kit | 설치 입력, 서비스, OmniRoute, 공개 모델 어댑터 | 설치 감사 완료; 실환경 검증 별도 |
| hermes-vps-setup | 서버·SSH·운영·복구 | 일부 구현; 실제 서버 검증 별도 |
| hermes-job-hunt-for-korean / hermes-agent-kit | 국내 채용·공개 ATS·수집 계약 | ATS·Wanted·Saramin 수집 및 질문·설정·시나리오 연결; 라이브 접속 미검증 |
| hermes-headhunt-kit | 투자 뉴스·기업 분석·점수화 | 제한된 투자 수집 및 보수적 점수화 재작성 |
| k-skill | 입찰·공시·한국 업무 스킬 | 관련 파일·법적/런타임 계약 감사 완료; 대량 채용 조회 제한·인증 노출 위험 경로 제외 |
| GTMOS | ICP·캠페인 브리프·근거 기반 초안·품질 게이트 | ICP·리스트 QA·초안 QA 스킬 연결; 발송·결제·CRM 변경 제외 |
| public-data-lens | 공공데이터 발견·비교·활용 계획 | 선택 MCP 연결 helper와 조사 스킬 구현; 입찰 공고 수집기와 구분 |
