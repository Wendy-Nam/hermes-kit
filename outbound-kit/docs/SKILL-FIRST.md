# 설치는 스킬에서 시작합니다

실제 설치를 이끄는 본체는 다음 스킬이며, 사용자 터미널의 `start.py`가 질문부터 설치·재개까지 잇는
하나의 시작점입니다.

```text
agent-skill/hermes-outbound-setup/SKILL.md
```

## 방법 1 — 코딩 AI에게 맡기기

키트 폴더를 Codex, Claude Code, Gemini CLI 같은 코딩 AI에서 열고 다음을 보냅니다.

> `agent-skill/hermes-outbound-setup/SKILL.md`를 읽고 설치를 시작해줘. 한 번에 질문 1~3개만 하고, 비밀값은 채팅에 묻지 마. 첫 연습 결과를 확인한 다음 선택 기능을 연결해줘.

AI는 질문 답을 `setup.json`에 저장하고, 계획을 먼저 보여준 뒤 실제 도구를 실행해야 합니다. 저장소와
터미널을 사용할 수 없는 일반 채팅 AI는 실제 설치가 아니라 안내만 할 수 있습니다.

## 방법 2 — 한 명령으로 시작하기

Python이 준비된 사용자 터미널에서 실행합니다.

```sh
python3 start.py --help
python3 start.py
```

Windows에서는 `python3` 대신 `py -3`을 사용합니다. 설정이 없으면 쉬운 질문을 시작하고, 있으면 같은
설정의 완료 기록을 확인해 이어갑니다. 계정 연결 없이 첫 연습 결과부터 보려면 `--offline`을 붙입니다.

## 방법 3 — 브라우저에서 설정만 만들기

`wizard.html`을 브라우저로 엽니다. “무슨 일을 할지 → 어떤 데이터를 쓸지 → 어디서 실행할지 → 모델과
메신저 → 선택 기능” 순서로 답하고 `setup.json`을 내려받습니다.

이 파일에는 키나 토큰이 없어야 합니다. 브라우저가 파일을 내려받았다고 설치가 끝난 것은 아닙니다.
키트 폴더로 옮긴 뒤 설치 도우미로 계속합니다.

```sh
python3 start.py --config setup.json
```

Windows에서는 `python3` 대신 `py -3`을 사용합니다.

## 방법 4 — 질문 도구로 설정만 만들기

Python이 이미 있다면 다음을 실행합니다.

```sh
python3 agent-skill/hermes-outbound-setup/scripts/prepare.py --output setup.json
python3 start.py --config setup.json
```

질문 도구는 내 컴퓨터/서버, Desktop 앱/터미널, 시나리오, 데이터, 모델, 선택 메신저와 서비스를
조건에 맞춰 묻습니다. 기존 `setup.json`은 덮어쓰지 않습니다.

## 처음 권장 선택

- 시나리오: 채용 신호
- 데이터: 연습 데이터
- 초안: 템플릿
- 장소: 내 컴퓨터
- 화면: Hermes Desktop 앱
- 메신저: 사용 안 함
- 결과: 새 Obsidian 볼트
- OMH: 사용
- OmniRoute·예약·서버 서비스: 첫 성공 뒤 결정

이렇게 시작하면 유료 AI 계정이나 봇 없이도 후보, 근거, 검토용 초안을 먼저 볼 수 있습니다. 실제 AI
초안은 모델이 짧은 질문에 답하는 것까지 확인한 뒤 명시적으로 선택합니다.

## 비밀값을 넣는 곳

모델 키, 봇 토큰, OAuth 코드, SSH 개인키 내용·암호는 AI 채팅, `setup.json`, ZIP, Obsidian에 넣지
않습니다. 사용자가 직접 연 비공개 터미널의 숨김 입력이나 공식 로그인 화면에만 입력합니다. 서버 주소,
사용자 이름, 공개 owner ID, SSH 키 **파일 경로**는 설정에 저장할 수 있습니다.

## 서버를 선택하면

SSH는 내 컴퓨터에서 서버에 안전하게 접속하는 방법입니다. 주소와 사용자 이름은 클라우드 제공자 화면에서
찾습니다. 개인키는 내 컴퓨터에 두고 `.pub` 공개키만 서버에 등록합니다. 스킬은 접속 계획, 키 생성,
fingerprint 확인, 접속 시험, 새 폴더 배포를 나눠 진행합니다. 파일 배포 성공을 24시간 운영 성공으로
표시하지 않습니다.

## “완료”의 기준

- Hermes Desktop 앱 또는 명령이 실제로 열림
- 모델을 선택했다면 짧은 질문에 실제 응답
- 메신저를 선택했다면 본인 계정의 실제 왕복과 비허용 사용자 차단
- 선택한 sample/file/live 데이터의 종류와 출처가 표시됨
- 후보, 후보가 된 근거, 사람이 검토할 메시지 초안의 저장 위치를 확인
- 예약·서버 계속 실행을 선택했다면 다음 실행 시각 또는 재부팅 뒤 재검증

설정 파일 생성, 로그인 저장, 서버 파일 복사만으로는 전체 완료가 아닙니다. 실패하면 스킬이 이미 끝난
단계, 막힌 이유, 다시 시작할 명령을 알려줘야 합니다.
