# Outbound kit — implementation ledger

Internal design/reviews are kept separately and are not included in the public distribution.
Historical completion claims in the pasted handoff are not proof of this implementation.

## Implemented components

1. Skill-first adaptive questions, actual prepare.py, shared schema, optional detailed HTML form.
2. installer.py plan/run/status, distinct OMH/routing steps, user-private credential prompts,
   resume evidence, configuration and execution-path binding.
3. SSH key preparation, independently confirmed host trust, read-only probe, isolated staged deployment.
4. Pinned official Hermes installer download/hash verification and conflict-checked execution command.
   Engine installation is an explicit user-terminal action, not silently run by the configuration form.
5. Telegram/Discord/both/none, token discovery and owner allowlists, existing settings preservation.
6. Conditional Webshare/Groq/Apify/Composio inputs, auth discovery, permission/cost/function gates.
7. Job imports, public ATS and investment WordPress adapters, conservative filters and evidence.
8. Obsidian Account→Evidence→Score→Draft→Review→Run chain with identity/approval gates.
9. Actual pinned OMH installation helper; OmniRoute optional container helper with Linux/macOS/Windows
   Docker prerequisites. Image architecture, Windows secret ACL and Docker VM memory are explicit gates.
10. Offline OMH recommendation→OmniRoute binding adapter. Generation does not imply activation.
11. Preparation guide, runnable demo, field audit and official-document assistance. PPT is cancelled
    and excluded from the public distribution.

## Required acceptance before production promises

- Fresh Mac/Windows engine/runtime installation and Windows security behavior on actual devices.
- Actual model response and selected bot roundtrips including unauthorized-user rejection.
- Actual SSH host/deployment, service start/restart/reboot and successful scheduled run.
- Real service functions, approved costs/scopes and permitted source access.
- Hermes loads OMH; a delegated task returns successfully.
- OmniRoute provider authentication, exact model discovery, two-turn tool probes, explicit routing
  activation and direct-model fallback. OAuth cannot be silently completed from a checkbox.
- Native desktop GUI packaging, procurement/overseas live adapters are not implemented features merely
  because those scenarios appear as requirements or manual-import paths.

No publishing, private-profile copying, paid actor run or outbound sending was performed.
