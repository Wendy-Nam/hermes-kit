# hermes-kit 0.21.2-k11

**k4~k10을 받은 학생은 `/setup`, `/doctor`가 Discord에 뜨지 않았습니다.** 이 릴리스로 재배포해야 합니다.

- **`/setup`이 등록되지 않던 문제.** Hermes는 플러그인 폴더를 패키지(`hermes_plugins.kit_setup`)로 불러오는데,
  kit-setup 모듈들은 같은 폴더의 파일을 `from discord_ui import build`처럼 바로 불러옵니다. 그래서 로드가
  `No module named 'discord_ui'`로 조용히 실패했고, 명령이 등록되지 않았습니다. 이제 `__init__.py`가 자기 폴더를
  경로에 추가합니다. 기존 단위 테스트는 모두 이 경로를 직접 넣고 돌아서 이 문제를 잡지 못했습니다. 실제 로더처럼
  패키지로 불러오는 테스트를 추가했습니다.
- **Webshare 프록시 확인이 늘 실패하던 문제.** `p.webshare.io`는 `<사용자명>-rotate` 형식만 받는데(영상 요약이 쓰는
  youtube-transcript-api도 이렇게 붙입니다) 확인할 때 이걸 빼고 보냈습니다. 그래서 맞는 값도 거부됐고,
  거부(407)가 "HTTP 0 · 인터넷 연결 확인"으로 잘못 표시됐습니다. 이제 `-rotate`를 붙여 확인하고, 거부는
  "로그인 정보가 아니라 Proxy 목록의 Username/Password"라고 안내합니다. 안내 링크도 API 키 화면이 아니라
  대시보드로 바꿨습니다.
- **`/setup`의 "봇 토큰이 없어 초대 링크를 만들지 못했습니다" 문구를 없앴습니다.** `/setup`을 실행할 수 있다는 것은 봇이
  이미 서버에 있다는 뜻입니다. 토큰은 Compose 환경변수에 있는데 `.env`만 읽어서 잘못 나오던 문구였습니다.
  초대 링크는 지금처럼 컨테이너 로그의 `[kit] 봇 초대:`로 안내합니다.

기존 학생은 데이터 볼륨을 유지하고 Hermes 태그를 `0.21.2-k11`로 바꿔 재배포하면 됩니다.
