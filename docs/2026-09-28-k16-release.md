# k16 — 막히는 두 지점을 없앱니다

`0.21.2-k16`. k15까지 설치는 정상 동작했지만, 학생이 **되돌릴 수 없어서** 막히는 두 가지가 남아 있었습니다.

## 고친 것

1. **봇 초대 링크를 다시 볼 수 있게 했습니다.** 링크는 첫 부팅 로그의 `[kit] 봇 초대:` 한 줄에만 있었습니다. 로그를 닫았거나 호스팅
   providers가 회전한 뒤에는 다시 볼 방법이 없고, 아직 서버에 초대하지 않은 학생은 `/invite`조차 쓸 수 없습니다.
   - 첫 부팅에 링크를 데이터 볼륨(`/opt/data/.kit-invite-url`, 0600)에 저장합니다. 링크에는 클라이언트 ID와 권한 비트만 있고 토큰은 없습니다.
   - 서버에 이미 초대했다면 **`/invite`** 로 다시 봅니다. 서버 소유자만, ephemeral(채널에 남지 않음)입니다.
   - 아직 초대하지 못했거나 토큰이 없으면, 키트가 **Developer Portal의 OAuth2 → URL Generator** 절차를 대신 알려 줍니다. 클라이언트 ID를 지어내는 일은 없습니다.
   - VPS에 접근할 수 있으면 컨테이너에서 `python /opt/data/plugins/kit-setup/owner.py` 로도 같은 링크가 나옵니다.
   - `/doctor` 에 **봇 초대 링크** 항목이 생겼습니다. 링크가 사라진 학생이 5초 안에 해결할 수 있는 문제인지, 지원 티켓인지가 갈립니다.

2. **고급 설정에 선택 기능 설명을 넣었습니다.** Composio·음성·차단 우회·수집·보조 모델은 키 이름(`COMPOSIO_CONSUMER_KEY` 등)으로만
   보였고, 무엇을 켜는 기능인지 알려 주는 곳이 없었습니다.
   - `/setup → 고급 설정`을 누르면 **선택 기능 안내**가 먼저 나오고, 각 줄에 기능 설명과 **현재 상태(설정됨 / 어떤 키가 필요한지 / 발급 URL)** 가 붙습니다. 키의 *값*은 절대 나타나지 않습니다.
   - **PC 옵시디언 노트** 줄은 Syncthing 설정의 장치 수를 읽어 "아직 PC 없음 / 연결된 장치 N대"로 표시합니다. 이는 파일이 PC에 도착했다는 뜻이 아니므로, 실제 확인은 PC 폴더를 보는 것으로 안내합니다.
   - 기존 **버튼 안내**(HomeView의 모든 버튼을 설명)는 두 번째 메시지로 그대로 유지됩니다.
   - `고급 설정 → PC 동기화` 버튼이 장치 ID 입력창을 바로 띄우던 것을, 순서를 설명한 뒤 입력창을 띄우도록 바꿨습니다. PC 옵시디언 절차는 마법사 버튼과 같은 문구를 씁니다.

## 학생 안내

- k15 이하를 받은 학생: 동작에는 변화가 없습니다. k16은 "설치 도중 막혔을 때"의 대체 경로와 설명을 더한 것입니다.
- 로그가 남아 있고 이미 초대한 학생은 아무것도 하지 않아도 됩니다.
- OmniRoute를 쓰는 학생은 3단계(적용하기 재시작)를 그대로 지켜 주세요 — k15 안내가 그대로 유효합니다.

## 확인한 것

- 단위 테스트 261개 통과(키트 플러그인 240 + 저장소 21). Discord SDK가 있는 이미지 안에서는 스킵 0건입니다.
- Compose 문법 검사 통과, `docker compose config` 확인.
- 비밀정보 스캔 클린, 첫 부팅 시드 2회 실행 후 상태 불변(boot-test).
- 설치 E2E(stage1 37/37, stage2 7/7, OmniRoute 3단계 포함): `/invite` 등록·소유자 권한·포털 안내, 마법자·고급 설정 화면(선택 기능 안내 + 버튼 안내), `/doctor`의 봇 초대 링크 항목까지 실제 Hermes 런타임에서 확인.
