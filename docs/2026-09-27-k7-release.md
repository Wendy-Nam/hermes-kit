# hermes-kit 0.21.2-k7

k6은 태그 CI의 OMH 검사에서 막혀 게시되지 않았습니다. k6의 작업별 경로는
Hermes 0.21.2에 없는 `delegate_task(routing=...)`에 의존했기 때문입니다. 그대로
배포됐다면 강화 모드를 켠 학생의 위임이 모두 차단됐을 것입니다. k7은 이를
업스트림 OMH 자체 라우팅 위에서 다시 구현합니다.

**OMH**
- 기본 팩 설치 시 모든 작업 종류가 보조 모델로 위임됩니다. 작업 종류별 추론 강도는
  OMH 권장값(최대 high)을 따르고, OMH의 모델별 보정 문구가 함께 켜집니다. 보정은
  high 이상 경로의 자식 작업에 붙으며, 실패해도 위임을 막지 않습니다.
- 작업별 모델과 대체 모델(최대 5개)을 저장할 수 있고, 저장은 작업별로 누적됩니다.
  `-`로 입력하면 그 작업만 기본값으로 되돌립니다. 대체 모델 전환은 OMH가 직접 처리합니다.
- **현재 경로·추천 보기**에서 설정과 OMH 추천 모델을 확인합니다.
- 보조 모델이나 OmniRoute 연결을 바꾸면 따로 지정하지 않은 작업도 따라갑니다.
- `/doctor`에 OMH 상태가 표시되고, 백업에 OMH 경로가 포함됩니다.

**한국형 스킬:** NomaDamas/k-skill(MIT)에서 고른 스킬 25개를 고정 커밋으로 포함합니다.
공통 6개는 모두에게, 나머지는 선택한 직무에 따라 설치됩니다. 실행 중 npm을
내려받지 않도록 원본 지침을 이미지 안의 스크립트 경로로 바꿔 두었습니다.

기존 학생은 데이터 볼륨을 유지하고 Hermes 태그를 `0.21.2-k7`로 재배포합니다.
OMH 기본 팩을 이미 설치한 학생은 **OMH 설정 → 보정 다시 켜기**를 누르면 권장
강도와 보정이 적용됩니다. 새 설치의 compact 스킬 목록에는 `k-skill`이 포함되며,
기존 학생의 설정은 바뀌지 않습니다.
