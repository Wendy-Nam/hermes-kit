# hermes-kit 0.21.2-k14

OmniRoute를 SSH나 모델 ID 없이 쓰게 한 릴리스입니다.

- **대시보드 열기 (15분).** `/setup → 고급 설정 → OmniRoute 연결 → 1. 대시보드 열기`. OmniRoute에 내장된
  Cloudflare 임시 터널로 `https://…trycloudflare.com` 링크를 만들어 본인에게만 보여 줍니다. 대시보드 비밀번호로
  로그인해야 하고, 15분 뒤 자동으로 닫히며 **대시보드 링크 닫기**로 바로 닫을 수도 있습니다. 봇이 그 사이 재시작되면
  닫혔는지 확인할 수 없으므로 OmniRoute 연결 화면에 경고를 띄웁니다. 필요할 때마다 같은 버튼으로 다시 열 수 있고(매번 새 주소),
  다시 열면 그때부터 15분입니다. SSH 터널은 더 이상 필요 없습니다.
- **모델 고르기.** `2. 모델 고르기`에서 비밀번호를 넣으면 대시보드에 연결한 계정의 대화용 모델(임베딩·음성·이미지
  제외)이 목록으로 나옵니다. 대화용·강한 작업용을 골라 **연결**을 누르면 k13과 같은 도구 호출 시험 후 연결합니다.
  목록에 없는 모델은 **ID 직접 입력**을 씁니다.

검증: 실제 OmniRoute로 모델 목록(대화용만 걸러짐), 임시 터널 열기 → 외부 접속 200 → 닫기를 확인했습니다. CI는
모델 목록과 모드 연결을 매번 확인합니다(터널은 외부 서비스라 CI에서 열지 않음).
