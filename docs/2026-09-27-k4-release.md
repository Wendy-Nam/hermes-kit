# hermes-kit 0.21.2-k4

스킬을 읽은 뒤 같은 대화에서 불필요하게 재조회하는 문제를 줄이는 공통 수정입니다. 개인 자아 플러그인이나 강사의 대화 규칙은 포함하지 않습니다.

- 신규 세션: 온전한 스킬 내용이 현재 대화에 남아 있으면 재사용합니다. 압축·누락·변경·새 참조 파일이 필요한 경우에는 다시 읽습니다.
- 기존 세션: 해시로 별도 저장된 프롬프트도 Hermes의 공식 조회·저장 API를 통해 교정합니다. 정확히 일치하는 옛 공통 안내문만 바꾸고 나머지 사용자 설정과 대화는 보존합니다.
- 업데이트: Hermes 이미지 태그를 `ghcr.io/wendy-nam/hermes-kit:0.21.2-k4`로 바꾸고 기존 데이터 볼륨을 유지한 채 재배포합니다. 새 학생용 Compose에는 이 태그가 지정됩니다. 이미 실행 중인 k3 컨테이너는 자동으로 바뀌지 않습니다.
- 검증: 새 프롬프트 생성, 실제 정규화 DB의 기존 세션 복원, 저장 후 재접속, 반복 적용을 이미지 내부에서 검사합니다. 모델이 스킬을 절대 재호출하지 않도록 강제로 차단하는 기능은 아닙니다.
