# hermes-kit 0.21.2-k12

`/setup`을 처음 설치하는 순서대로 바꾸고, 역할별 프로필을 추가한 릴리스입니다.

- **설정 순서 화면.** `/setup`을 열면 버튼 15개 대신 번호가 붙은 4단계가 먼저 나옵니다: 대화 모델 연결 →
  Gemini 키 → 직무 선택 → 권장 설정 적용. 끝난 단계는 ✅로 표시됩니다. ChatGPT 로그인과 API 연결에는 권장 모델
  ID가 미리 채워져 있어 학생이 모델 ID를 찾아 입력하지 않아도 됩니다(실제 응답 확인은 그대로). 이전 화면은
  **고급 설정**으로 옮겼습니다.
- **권장 설정 적용 한 번으로** OMH 기본 팩, 역할 프로필 세 개, 연결 확인, 유지보수 등록, 재시작까지 진행합니다.
- **역할 프로필.** `research`(조사·출처 정리), `coder`(코드·파일·자동화), `creator`(글·문서·콘텐츠)를 만듭니다.
  기본 봇이 지휘자입니다. 짧은 병렬 작업은 OMH로 위임하고, 오래 걸리거나 여러 단계인 일은 kanban 카드로 역할
  프로필에 맡깁니다. 역할 프로필은 봇 토큰을 갖지 않으며(두 프로필이 같은 토큰을 쓰면 충돌), 적용하기와 부팅
  때마다 대화 모델·제공자 설정·서비스 키를 기본 봇과 맞춥니다. 모든 역할이 준비됐을 때만 기본 봇의 SOUL에
  맡기는 규칙을 한 번 추가합니다.
- **PC 옵시디언 안내**를 설정 화면 안으로 넣었습니다(Syncthing 장치 ID 입력까지 한 화면).
- **Cline 무료 후보 조회를 없앴습니다.** 제공자와 무료 모델 선택은 OmniRoute 대시보드에서 합니다.

기존 학생은 데이터 볼륨을 유지하고 태그를 `0.21.2-k12`로 바꿔 재배포한 뒤, `/setup`의 **4. 권장 설정 적용**을
한 번 누르면 역할 프로필이 추가됩니다. 이미 설치한 OMH는 보존합니다.

확인하지 못한 것: 실제 ChatGPT 계정에서 역할 프로필이 기본 봇의 로그인을 이어 쓰는지(Hermes는 프로필이 루트
로그인을 읽도록 되어 있음), 학생 계정에서 권장 모델 ID(`gpt-6-luna`, `deepseek/deepseek-v4.1-flash`)가 통하는지는
리허설에서 확인해야 합니다.
