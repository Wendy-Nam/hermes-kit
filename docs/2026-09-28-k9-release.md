# hermes-kit 0.21.2-k9

강사 서버에서 쓰던 Hermes 코어 수정 중 학생에게도 해당하는 세 가지를 옮겼습니다.
모두 고정한 Hermes 0.21.2 소스에서만 적용되며, 원본이 다르면 이미지 빌드가 실패합니다.

- **터미널 실패 안내 중복 제거:** 재시도를 다 쓴 모델 오류가 Discord에 같은 안내로 두 번
  나가던 문제를 한 번으로 줄입니다. 중간 오류는 그대로 보입니다.
- **프로세스 도구 이름 안내 수정:** 모델에게 보이는 안내가 없는 도구 `process(action=...)`를
  가리켜 헛호출하던 문제를 실제 도구 `process_manage`로 고칩니다.
- **Discord 대용량 영상:** 업로드 한도를 넘는 영상은 거절 안내만 보내던 대신, 이미지에 있는
  ffmpeg로 한도의 90%에 맞춰 다시 인코딩해 보냅니다. 너무 길어 화질이 150kbps 아래로
  떨어지거나 인코딩이 실패하면 예전처럼 크기 안내를 보냅니다.

옮기지 않은 것: `openai-provider-kwarg`(기본 Hermes는 provider 설정을 `extra_body`에 넣어
해당 경로가 생기지 않음), 멀티 프로필·개인 크론·FreeLLMAPI·snow-search 관련 패치.

기존 학생은 데이터 볼륨을 유지하고 Hermes 태그를 `0.21.2-k9`로 재배포합니다. 설정 변경은 없습니다.
