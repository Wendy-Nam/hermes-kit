# 대화 모델 선택 가이드 (무료·저비용 중심)

`/setup` 1단계에서 **대화 모델 하나**를 정해야 합니다. 이 문서는 "무료로 되는 것", "돈이 드는 것",
"학생이 실제로 뭘 해야 하는지"만 정리합니다. 요금은 2026-09-28 기준이며, 각 서비스에서 최신 가격을
직접 확인한 뒤 공지해 주세요.

## 먼저 알아야 할 것

**완전히 무료인 대화 모델은 이 키트에서 기본으로 권장하지 않습니다.** 이유는 셋입니다.

- 무료 티어는 RPM(분당 요청)·RPD(일일 요청) 한도가 작습니다. 수업 시간에 30명이 한꺼번에 질문하면
  개인 한도를 소진한 학생은 수업 내내 "한도 초과"만 봅니다.
- 무료 티어는 **대화 내용을 Google 제품 개선에 사용**합니다(유료 티어는 하지 않음). 학생 개인 노트
  내용을 그대로 올리게 되는 셈이라 수업에서는 다루기 어렵습니다.
- 한도가 남아도 모델 목록이 바뀌어, 오늘 확인한 모델 ID가 다음 주에 사라집니다. `/setup`은
  정확한 모델 ID를 요구하므로 그때마다 다시 입력해야 합니다.

그래도 **비용을 최소화해야 하는 경우**의 선택지는 아래와 같습니다.

## 선택지

| 선택지 | 비용 | 학생이 해야 할 것 | 비고 |
|---|---|---|---|
| **ChatGPT 로그인** (권장) | 이미 가지고 있는 ChatGPT Plus 구독에 포함. 별도 API 결제는 없음 | `/setup` → **ChatGPT로 로그인** → 링크 열고 코드 입력 | API 키를 만지지 않습니다. 학생이 이미 쓰던 방식 그대로라 수업에서 가장 막히지 않습니다. **OAuth 승인은 학생 본인이 하는 것이며, 강사가 대신 승인하지 않습니다.** |
| **OpenCode Go** (보조) | $10/월 구독 | OpenCode Zen에서 구독 후 API 키 복사 → `/setup → API 키로 연결` → 모델 ID는 `opencode-go/<모델ID>` 형식 | 여러 오픈 모델에 접근. **트래픽이 코딩 에이전트 성격이어야 정상 취급**되며, 범위를 벗어나면 차단될 수 있습니다. 데이터 보관 정책이 모델마다 다릅니다(대부분 0일, 일부 30일) |
| **Command Code Go** (보조) | $1/월에 $10 크레딧(월마다 갱신) | Command Code에서 Go 플랜 가입 → 키 복사 | 가장 저렴한 유료 선택지. 일부 모델은 기간 한정 무료입니다. Go 플랜은 **Provider API 접근이 없습니다** |
| **Gemini API 키** (영상 요약, 필수) | Free Tier 무료(일일 500 RPD, 분당 5 RPM, 입력 1M/일) | https://aistudio.google.com/apikey | 키 자체는 무료지만 **Free Tier는 대화 내용이 Google 제품 개선에 사용**됩니다. 키트는 이 키를 **영상 요약 전용**으로만 씁니다 |

## 무료 티어를 대화 모델로 써야 할 때

수업이 연습이라 데이터가 민감하지 않고, 개인 한도가 남아 있다면 가능합니다. 다만 다음을 학생에게
반드시 말해 주세요.

- **Free Tier에서 콘텐츠가 학습에 사용됩니다.** 개인 노트·회사 자료를 올리지 않습니다.
- RPM/RPD 한도를 반드시 미리 공지합니다. AI Studio의 **Rate limit** 화면에서 현재 적용 한도를 확인하게 합니다.
- 한도 초과 시 오류는 `429`이며, 학생별 소비량이 아니라 프로젝트 단위로 차감됩니다.
- 유료로 올리려면 AI Studio에서 먼저 결제를 연결해야 합니다. 결제가 연결되면 대화 내용 사용은 중단되지만
  요금이 발생합니다.

## OmniRoute를 쓸 때

OmniRoute는 **구독이 아니라 여러 계정을 한 대시보드에서 묶는 중계**입니다. 대시보드에서 계정을 직접
연결하면 "대화용"과 "강한 작업용" 모델을 각각 최대 5개까지 골라 하나의 콤보로 만들 수 있습니다.
이때 모델을 고르는 기준은 가격이 아니라 **목적**입니다.

- 대화용: 일상 대화·요약·정리에 자주 쓸 모델.
- 강한 작업용: 도구 호출, 조사, 긴 코딩처럼 실패하면 다시 시도하는 작업.

**보조 규칙:** 지금 쓰던 직접 연결 모델이 대체 경로로 남으므로, OmniRoute가 멈춰도 봇이 답합니다.
웹 스크래핑 제공자는 쓰지 않습니다. 대시보드는 15분 임시 링크로 열며, 사용이 끝나면
**대시보드 링크 닫기**를 누릅니다.

## 강사용 공지 템플릿

수업 전날 학생들에게 다음 그대로 보내면 됩니다.

```
대화 모델: /setup 첫 단계에서 고릅니다.
· 이미 쓰고 계신 ChatGPT 구독이 있으면 "ChatGPT로 로그인"을 쓰세요. API 키를 만지지 않습니다.
· 다른 API를 쓰시려면 제공자 API 키와 정확한 모델 ID가 필요합니다. 그 모델이 지금 본인 계정에서
  실제로 응답하는지는 기수 시작 전에 제가 한 번 확인해 공지합니다.
· 비용: 모델 사용료와 VPS 요금은 각 서비스에서 따로 나옵니다. 채팅창에 API 키나 봇 토큰을
  절대 붙여 넣지 마세요.
```

## 강사가 사전에 확인할 것

1. 이번 기수에 공지할 **대화 모델 ID**를 실제 계정으로 한 번 호출해 확인합니다. `/setup`은 틀린 ID를
   받아들이지 않습니다(연결 확인에서 실패).
2. AI Studio에서 학생 프로젝트의 Free Tier 한도(RPM/RPD)를 확인합니다.
3. ChatGPT 로그인은 학생 본인의 OAuth 승인 한 단계이므로, 강사 계정으로 대신 승인하지 않습니다.
4. OmniRoute를 쓰기로 했다면 **기본 프로젝트를 먼저 배포**했는지, `KIT_OMNIROUTE_PASSWORD`를
   정했는지 확인합니다(비우면 기동을 거부합니다).
