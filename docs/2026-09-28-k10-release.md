# hermes-kit 0.21.2-k10

설치를 단순하게 만든 릴리스입니다.

- **보조 모델은 선택 사항입니다.** 설치 완료에는 대화 모델 하나와 Gemini 키(영상 요약)만 필요합니다.
  보조 모델을 지정하지 않으면 하위 작업(위임)도 대화 모델이 처리하고, `/doctor`는 이를 정상으로
  표시합니다. OMH 기본 팩도 보조 모델 없이 설치할 수 있으며, 이때 작업별 경로의 기본값은 대화 모델이고
  대화 모델을 바꾸면 함께 따라갑니다. 위임을 더 싼 모델로 돌리고 싶을 때만 `aux`로 지정합니다.
- **비공개 팩 입력란을 없앴습니다.** `KIT_ACCESS_CODE`·`KIT_PACKS_REF`와 관련 다운로드 코드를 제거했습니다.
  직무 스킬 개선은 이미지 릴리스로 배포합니다. Compose 환경변수는 `DISCORD_BOT_TOKEN` 하나입니다.
  예전에 두 값을 넣어 둔 학생은 그대로 두어도 무시됩니다.
- **Composio 이름을 바로잡았습니다.** "구글 연동"이 아니라 Composio MCP 앱 연동입니다. Composio에서 연결한
  앱(Gmail·캘린더·Notion 등)의 도구를 Hermes가 씁니다. 기존 설치 상태는 그대로 유지됩니다.
- README에 `/setup`에서 받는 키 표를 넣었고, 강사용 [설치 도우미 안내](instructor-install-guide.md)를 추가했습니다.

기존 학생은 데이터 볼륨을 유지하고 Hermes 태그를 `0.21.2-k10`으로 재배포합니다. 설정 변경은 없습니다.
