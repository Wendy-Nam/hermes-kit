# hermes-kit 0.21.2-k5

크론이 실행 한도에 걸려 부분 답변만 만든 경우 성공으로 기록하지 않습니다.
부분 보고서는 오류 산출물에 남기고 실패 기록을 보존합니다. 정상 완료와
의도적인 무응답 동작은 유지합니다. 실제 배포 런타임과 실행 DB를 검사합니다.

선택 OmniRoute Compose는 별도 `omniroute-rtk-json-1` 이미지를 사용합니다.
RTK의 Hermes JSON 어댑터가 `output`만 압축하고 나머지 필드를 보존합니다.
RTK 활성화는 별도이며 기존 압축 프로필을 변경하지 않습니다.

OMH는 선택 설치하는 upstream 기본 팩이며 초기에는 선택한 보조 모델 하나를
모든 작업 분류에 연결합니다. 강사의 여러 모델 체인·개인 보정 패치와 동일하지
않습니다. 개인 계정·자아 기능·대화·크론은 포함하지 않습니다.

기존 학생은 데이터 볼륨을 유지하고 Hermes 태그를 `0.21.2-k5`로 재배포합니다.
OmniRoute는 별도 프로젝트이므로 심화 Compose도 별도로 갱신해야 합니다.
