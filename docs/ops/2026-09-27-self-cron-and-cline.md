## 자아 예약 작업

- 계획만 출력하고 실행하지 않는 tick을 실패로 감지한다. 실패 후 재시도는 6시간 구간별로 제한하며 완료처럼 처리하지 않는다.
- freework 주간 작업은 실제 보드 경로와 읽기 전용 명령을 사용하도록 고쳤다.
- source text mismatch는 원문의 강조 기호를 모델이 지워 생겼다. 원문 검증을 약화하지 않고 메시지 ID와 해시로 DB 원문을 전달하는 도우미를 추가했다. 정상 critic 거절은 배치 중단과 구분한다.
- sweep pack의 날짜·출처·증거 해시는 기계적으로 구성한다. 모델이 원문과 날짜를 다시 작성하지 않는다. 이미 기록된 pack은 덮어쓰지 않는다.
- 해당 날짜의 실패 pack은 백업 후 기존 검토 9건·수락 3건을 그대로 유지하여 메타데이터만 복구했다. 격리 DB 검증 후 실제 기록이 성공했고 `sweep_evidence_ok=true`, `should_sweep=false`를 확인했다. 새 욕망이나 승격을 생성하지 않았다.

검증: runtime 관련 16개, trigger 7개, cron 계약 9개 통과. 과거 실패 기록 때문에 남는 감사 FAIL을 성공으로 조작하지 않았다. 10건 수집 제한의 페이지 처리와 이미 완료된 기록의 재호출 동작은 추가 개선 여지가 있다.
