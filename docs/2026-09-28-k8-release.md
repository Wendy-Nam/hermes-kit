# hermes-kit 0.21.2-k8

k7의 작업별 경로는 에이전트가 위임 전에 `omh_delegate_route`를 부를 때만 적용됐습니다.
부르지 않으면 하위 작업이 추론 강도 없이 보조 모델로 넘어가 작업별 모델·강도·보정이
모두 빠졌습니다. k8은 이 경우를 막습니다.

**OMH**
- 이번 대화에서 경로를 정하지 않은 위임은 한 턴에 한 번 되돌려 `omh_delegate_route`로
  작업 종류를 먼저 정하게 합니다. 다시 시도하면 보조 모델 기본값으로 진행하므로, 경로를
  정할 수 없는 상황(도구 없음, 대체 모델 소진)에서도 위임이 멈추지 않습니다.
- 다른 대화가 동시에 정해 둔 경로로는 위임하지 않습니다. 그 대화도 자기 경로를 정하게
  되돌리므로 채널이나 크론이 동시에 돌 때 경로와 보정이 섞이지 않습니다.
- k7 이전에 설치해 SOUL에 위임 규칙이 없는 학생은 보정을 켤 때(기본 팩 설치, **보정 다시
  켜기**, 보조 모델 변경) 표시된 한 단락이 SOUL 끝에 한 번 추가됩니다. 이미 규칙을 쓴
  SOUL은 바꾸지 않습니다.
- 보정을 켜 둔 학생은 재배포 후 첫 부팅에서 자동으로 k8 방식으로 바뀌고, 저장한 작업별
  모델은 유지됩니다. 버튼을 누를 필요가 없습니다.
- `omh update`는 키트의 훅 파일을 교체해 경로 요청과 보정을 끕니다. 키트가 설치한 OMH는
  업데이트하지 마세요.

기존 학생은 데이터 볼륨을 유지하고 Hermes 태그를 `0.21.2-k8`로 재배포합니다. k5에서 OMH
기본 팩만 설치하고 보정을 켠 적이 없는 학생은 **OMH 설정 → 보정 다시 켜기**를 한 번 누릅니다.
