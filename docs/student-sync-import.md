# PC 동기화와 기존 대화 가져오기

## PC와 개인 서버 연결

1. PC에 [Syncthing](https://syncthing.net/downloads/)을 설치하고 실행합니다.
2. PC의 Syncthing 화면에서 **동작 → ID 표시**를 열어 장치 ID 전체를 복사합니다. API 키나 인증서는 복사하지 않습니다.
3. Discord `/setup`의 PC 동기화에서 PC 장치 ID를 입력합니다.
4. 표시된 **서버 장치 ID**를 PC에서 확인하고 장치 추가를 수락합니다. 요청이 보이지 않으면 PC의 **원격 장치 추가**에 서버 ID를 입력합니다.
5. `hermes-work`와 `hermes-personal` 공유 요청을 각각 수락합니다. PC의 빈 폴더 두 개를 선택하세요. 업무 폴더와 개인 폴더를 같은 경로로 설정하지 않습니다.
6. PC 개인 폴더에 `동기화-확인.txt`를 만들고 Syncthing 양쪽 상태가 최신인지 확인합니다. 서버에서 만든 파일도 PC에 도착해야 연결 확인이 끝납니다.

서버 설정 저장 메시지는 PC 수락이나 파일 전송 완료를 뜻하지 않습니다. 연결되지 않으면 양쪽 Syncthing이 실행 중인지, VPS의 TCP/UDP 22000 연결이 가능한지 확인하세요. 웹 관리 화면 8384 포트를 인터넷 전체에 열 필요는 없습니다.

이 설정은 서버의 `vaults/work`, `vaults/personal` 두 폴더만 공유합니다. `.env`, 인증 파일, 서버 전체 데이터는 공유하지 않습니다. **개인 폴더에 넣은 대화는 연결한 PC와 개인 서버 사이에서 동기화됩니다.** 연결할 PC가 본인 기기인지 확인하세요. 기존 장치·다른 공유 폴더·폴더별 옵션은 보존합니다. 같은 폴더 ID가 다른 경로를 가리키면 자동 변경하지 않고 중단합니다.

오류가 나면 일부 설정만 저장됐을 수 있습니다. 같은 PC ID로 다시 실행해도 같은 장치나 폴더를 중복 생성하지 않습니다. 동기화 해제는 Syncthing에서 해당 장치의 폴더 공유를 해제하세요. 이 가이드는 기기나 파일 삭제를 수행하지 않습니다.

## ChatGPT·Claude 대화 ZIP 가져오기

1. 사용하는 서비스의 데이터 내보내기 기능으로 ZIP을 내려받습니다. 다른 사람에게 ZIP을 보내지 마세요.
2. PC **개인 폴더** 안에 `Inbox/import` 폴더를 만들고 ZIP을 복사합니다. 동기화가 완료될 때까지 기다립니다.
3. `/setup`의 대화 가져오기에서 `export.zip`처럼 **파일명만** 입력합니다. 전체 경로나 URL은 입력하지 않습니다.
4. 완료 메시지의 새 대화·건너뜀·기존 파일 보존 개수를 확인합니다. 결과는 개인 폴더의 `Archive/chatgpt` 또는 `Archive/claude`에 대화별 Markdown으로 생깁니다.

지원 형식은 ZIP 안의 `conversations.json` 하나입니다. ChatGPT는 `current_node`가 가리키는 대화 분기만 읽습니다. Claude는 `chat_messages`의 텍스트를 읽습니다. 이미지·음성·첨부파일은 가져오지 않습니다. HTML과 Markdown 표현은 실행하거나 외부 이미지를 불러오지 않도록 텍스트로 저장합니다. 제목은 파일 안에서 볼 수 있고, 파일명은 중복 방지를 위한 대화 ID 해시입니다.

같은 ZIP을 다시 실행해도 동일한 대화 파일은 건너뜁니다. 이미 수정한 파일이나 내용이 다른 기존 파일은 덮어쓰지 않고 보존합니다. 최신 내보내기가 더 긴 대화를 포함해도 자동 병합하지 않으므로, 보존 개수가 있으면 기존 파일을 확인한 뒤 별도로 판단하세요.

ZIP은 최대 100 MiB, 전체 압축 해제 예상 크기는 200 MiB, `conversations.json`은 40 MiB까지 허용합니다. 잘못된 경로·심볼릭 링크·암호화 ZIP·깨진 대화 분기는 거절합니다. 오류 시 이미 저장한 대화 개수도 표시합니다.

가져오기는 로컬 파일 변환이며 모델 호출, 자동 기억 등록, 외부 서비스 업로드를 하지 않습니다. 원본 ZIP은 자동 삭제하지 않습니다. 성공 여부를 확인한 뒤 필요에 따라 본인이 삭제하세요. Syncthing 공유 폴더에서 삭제하면 연결 기기에도 삭제가 동기화될 수 있습니다.

## 구현 참고

Syncthing API 계약은 공식 [설정 엔드포인트](https://docs.syncthing.net/rest/config.html), [장치 ID 검증](https://docs.syncthing.net/rest/svc-deviceid-get.html), [서버 상태](https://docs.syncthing.net/rest/system-status-get.html)를 따릅니다. 장치 ID 체크섬은 서버가 검증합니다. `config.xml`은 API 키를 읽는 데만 사용하고 수정하지 않습니다. 설정 변경은 devices/folders의 개별 POST로 적용합니다.

단위 테스트는 외부 서비스에 접속하지 않습니다. 실제 PC에서 장치 수락과 양방향 파일 도착 확인은 학생 배포 전 별도 점검 항목입니다.
