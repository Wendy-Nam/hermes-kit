# hermes-kit 0.21.2-k6

OMH 선택 강화가 추가됩니다. OMH 기본 팩을 설치한 뒤 **OMH 설정**에서 작업
분류별로 본인이 연결한 제공자의 모델 하나 또는 OmniRoute 콤보 하나와 추론
강도를 정합니다. 저장 전에 격리된 짧은 요청으로 실제 응답을 확인하고,
실패하면 아무것도 저장하지 않습니다. 위임할 때는 같은 세션에서 준비한 경로만
통과시키고, 업스트림 OMH의 네이티브 보정 문구를 자식 컨텍스트에 붙입니다.
기본 대화 모델과 프로필 기본값은 바꾸지 않습니다. 끄면 기본 OMH 동작으로
정확히 복원됩니다.

업스트림 `omh setup`은 설치할 때 `<hermes_home>/profiles/` 아래 모든 봇
프로필 홈에 자기 등록을 복사했습니다. k6는 설치 전에 그 홈들을 기록하고
설치 성공·실패·중단 어느 경우에도 바이트 단위로 되돌립니다. 프로필의
`config.yaml`·`.env`·스킬은 바뀌지 않으며, 캐시도 홈 밖 작업 디렉터리로
돌립니다. 강사의 개인 모델 체인·자아 설정·커스텀 보정 패치는 여전히 복사하지
않습니다.

선택 OmniRoute Compose는 `omniroute-rtk-json-2` 이미지를 사용합니다. RTK가
켜져 있을 때 Hermes JSON 결과의 `output`만 압축하고 나머지 필드는
보존합니다. RTK 활성화는 별도이며 기존 압축 프로필을 변경하지 않습니다.

기존 학생은 데이터 볼륨을 유지하고 Hermes 태그를 `0.21.2-k6`으로
재배포합니다. OmniRoute는 별도 프로젝트이므로 심화 Compose도 별도로
갱신해야 합니다.
